# Test data

`commonmark-spec-0.31.2.json` contains the examples of the
[CommonMark Spec, version 0.31.2](https://spec.commonmark.org/0.31.2/)
by John MacFarlane, licensed under the
[Creative Commons Attribution-ShareAlike 4.0 International License](https://creativecommons.org/licenses/by-sa/4.0/).
It is used unmodified as a test corpus by `tests/roundtrip.py`.
